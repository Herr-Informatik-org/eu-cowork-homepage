„Mach mir aus diesen Zahlen eine Excel-Auswertung" ist eine der Aufgaben, für die
Mitarbeitende eine KI am ehesten brauchen. Diese Seite beschreibt, was dabei passiert, was
davon ohne zusätzliche Technik funktioniert und was ein Backend voraussetzt.

Code-Ausführung und Artefakte kommen von [LibreChat](https://www.librechat.ai/docs). Von uns
kommt die Auswahl und Vorbereitung des Ausführungs-Backends.

## Was Sie davon haben

Sie schreiben: „Aus dieser Liste bitte eine Excel-Datei mit einer Auswertung pro Monat."
Der Kollege rechnet, erzeugt die Datei und legt sie als Download in den Chat. Sie klicken
darauf und haben die Datei.

Das gilt für Excel, CSV, Word und PDF gleichermassen, und auch für Auswertungen aus einer
angehängten Tabelle. Wichtig ist nur eines: Sagen Sie, was in der Datei stehen soll, nicht
wie sie technisch entstehen soll.

Wenn Sie eine schon erzeugte Datei ändern wollen, sagen Sie das im selben Chat. Der Kollege
lädt die vorhandene Datei und passt sie an, statt sie neu zu bauen. So bleibt erhalten, was
Sie vorher abgesprochen haben.

<Aside type="note" title="Der Weg zum Code bleibt im Hintergrund">
Skripte, Befehle und interne Pfade werden nicht angezeigt. Sie bekommen die Datei und eine
kurze Zusammenfassung, was drin steht. Das ist Absicht: die Zielgruppe sind Fachleute, keine
Entwickler.
</Aside>

## Artefakte: Ergebnisse direkt im Chat

Etwas anderes als die Code-Ausführung sind die **Artefakte**. Damit stellt der Kollege
Inhalte direkt in einem Seitenbereich der Oberfläche dar, statt sie als Codeblock
auszugeben:

| Art | Beispiel |
|---|---|
| Mermaid | Ablaufdiagramm, Organigramm, Zeitachse |
| SVG | einfache Grafiken und Schemata |
| HTML | eine gestaltete Seite oder Tabelle zum Anschauen |
| React | eine kleine, bedienbare Oberfläche, etwa ein Rechner |
| Markdown | formatierte Dokumente |

**Artefakte brauchen kein Ausführungs-Backend.** Sie sind auf den ausgelieferten Modellkarten
aktiv und funktionieren nach der Installation sofort. Wer also nur ein Diagramm oder eine
Übersicht möchte, braucht die Code-Ausführung nicht.

<Aside type="caution" title="Vorschau braucht HTTPS">
Die interaktive Vorschau läuft nur in einem sicheren Kontext. Ohne gültiges Zertifikat bleibt
sie leer oder meldet einen Verbindungsfehler. Das ist kein Fehler des Backends, sondern eine
Browser-Regel. Der saubere Weg ist ein echter Domainname mit gültigem Zertifikat.
</Aside>

## Im Auslieferungszustand ist die Code-Ausführung aus

Ab Werk ist die Code-Ausführung nicht freigeschaltet. Der Grund ist derselbe wie bei der
Dateisuche: die Ausführung braucht ein eigenes, abgeschottetes Backend, das nicht Teil der
Grundinstallation ist. Ohne Backend wäre der Knopf ein toter Knopf, und jeder Versuch endete
in einem Fehler.

Sie entscheiden also bewusst, ob Sie diese Funktion anbieten.

## Für Admins

Die Code-Ausführung ist die einzige Stelle, an der erzeugter Code auf Ihrer Maschine läuft.
Entsprechend gehört sie in eine eigene, isolierte Umgebung, die getrennt von der übrigen
Installation betrieben und nie zwischen Instanzen geteilt wird.

Bei der Auswahl eines Backends sind drei Punkte entscheidend:

- **Isolation.** Ausgeführter Code darf weder an die Daten der Instanz noch an das restliche
  Netz herankommen.
- **Erreichbarkeit.** Das Backend wird ausschliesslich intern angesprochen. Von aussen wird
  dafür nichts gebraucht; Diagnosezugänge gehören auf die Loopback-Adresse oder in einen
  SSH-Tunnel.
- **Ausgehender Verkehr.** Welche Ziele ausgeführter Code im Internet erreichen darf, legen
  Sie auf Host- oder Netzebene fest. Planen Sie diese Freigabeliste bei der Einrichtung mit
  ein und halten Sie die erlaubten Ziele in Ihrem Betriebshandbuch fest.

Wird die Code-Ausführung gar nicht gebraucht, lassen Sie das Backend weg: Im
Auslieferungszustand ist sie ausgeschaltet.

<Steps>

1. **Recht setzen.** Das Recht **Code-Interpreter** steht im Rollen-Editor unter
   **Werkzeuge**. Wer die Ausführung nur einzelnen Rollen geben will, pflegt es
   ausschliesslich dort.

2. **Auf den Modellkarten aktivieren**, damit das Modell das Werkzeug von selbst benutzt,
   ohne dass jemand klickt.

3. **Prüfen**, ob in einem frischen Chat eine erzeugte Datei tatsächlich als Download
   erscheint.
