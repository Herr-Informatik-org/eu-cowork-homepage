## Diese Dokumentation und LibreChat

EU Cowork AI baut auf [LibreChat](https://www.librechat.ai) auf, einer quelloffenen
Chat-Plattform unter MIT-Lizenz. Die Chat-Oberfläche, das Agenten-System, die
Dateiverarbeitung und die Modellanbindung stammen von dort. Ergänzt haben wir alles,
was ein Unternehmen für den geregelten Betrieb braucht: ein eigenes Admin-Panel,
ein Rechte-Gateway vor allen Konnektoren, Verbrauchsmessung mit Budgets und ein
Installationspaket für den eigenen Server.

Diese Dokumentation beschreibt das Gesamtsystem und sagt an jeder Stelle, woher ein
Baustein kommt. Wo die Dokumentation von LibreChat tiefer geht, verweisen wir dorthin,
statt sie schlechter nachzuerzählen. Welcher Baustein von wem stammt, steht im Detail
unter [LibreChat und EU Cowork](/docs/referenz/librechat-und-eu-cowork).
