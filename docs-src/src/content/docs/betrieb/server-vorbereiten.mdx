EU Cowork AI wird self-hosted betrieben und läuft als Docker-Compose-Anwendung, so wie
LibreChat selbst es für den eigenen Betrieb vorsieht. Bevor die Anwendung installiert wird,
muss die Maschine dafür vorbereitet sein.

## Was der Server mitbringen muss

- Eine aktuelle Linux-Distribution mit Langzeitunterstützung.
- Docker mit aktuellem Compose-Plugin, so wie LibreChat es für den Self-Hosting-Betrieb
  voraussetzt.
- Genug Arbeitsspeicher, CPU und Plattenplatz für die geplante Nutzerzahl, siehe
  [Systemanforderungen](/docs/erste-schritte/systemanforderungen).
- Eine Firewall, die eingehende Verbindungen auf das Nötige beschränkt, sowie Zeitsynchronisation
  und automatische Sicherheitsaktualisierungen des Betriebssystems.
- Log-Rotation für Docker, damit die Container-Protokolle die Systemplatte nicht über Wochen
  volllaufen lassen.

## Vorbereitung der Maschine

Diese Grundlagen werden eingerichtet, bevor die Anwendung dazukommt. Die Vorbereitung betrifft
allein das Betriebssystem und die Container-Umgebung; Konfiguration und Anwendung folgen erst im
nächsten Schritt, siehe [Installation](/docs/betrieb/installation). Für diesen Schritt liegen dem
Auslieferungspaket entsprechende Hilfsmittel bei.

<Aside type="note" title="Detaillierte Anleitung im Betriebshandbuch">
Der genaue Ablauf und die Prüfliste nach der Vorbereitung stehen im Betriebshandbuch,
das dem Auslieferungspaket beiliegt. Kunden erhalten es zusammen mit dem Zugang.
</Aside>
