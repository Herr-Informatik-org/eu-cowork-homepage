EU Cowork AI est du véritable open source, et les composants tiers livrés avec lui sont placés
sous leurs propres licences. Cette page dit ce que cela signifie en pratique et énumère chaque
composant avec sa licence. Elle s’adresse à tous ceux qui, avant un achat, doivent savoir à quoi
ils s’engagent.

## La licence du produit dans son ensemble

L’intégralité de notre propre code est publiée sous **licence MIT**. C’est l’une des licences
les plus permissives qui soient : vous pouvez utiliser, modifier, redistribuer et exploiter
commercialement le logiciel, tant que le texte de la licence et la mention de droit d’auteur
sont conservés.

Ce que cela signifie concrètement pour vous en tant que client :

| Engagement | Ce qu’il y a derrière |
|---|---|
| **L’auto-hébergement est gratuit** | Vous ne payez rien pour le logiciel. Ce qui se paie, c’est l’exploitation, le support et l’intégration, si vous souhaitez les acheter à quelqu’un |
| **Aucune limite par utilisateur** | Le nombre d’utilisateurs n’est nulle part limité techniquement ni plafonné par la licence. Dix personnes coûtent la même chose que trois cents, à savoir rien |
| **Aucune fonction réservée** | Il n’existe pas d’édition entreprise dotée de fonctions supplémentaires. Ce qui se trouve dans le dépôt constitue l’ensemble des fonctionnalités |
| **Aucune clause de marque** | Nom, logo, favicon et texte d’accueil relèvent de la configuration. Vous pouvez renommer l’interface aux couleurs de votre propre entreprise, sans avoir à respecter un nombre d’utilisateurs ni un délai |
| **Pas de copyleft** | Vous n’êtes pas tenu de publier vos propres extensions |

Le texte de la licence se trouve dans le fichier `LICENSE` du dépôt, où figure également le
titulaire des droits.

<Aside type="note" title="Pourquoi cela est dit explicitement">
D’autres projets de ce domaine sont formellement à code ouvert, mais plafonnent le nombre
d’utilisateurs pour le retrait du logo de l’éditeur, ou dissimulent des fonctions
d’administration derrière une édition payante. C’est ce qui nous a conduits à placer la question
de la licence tout au début.
</Aside>

## Pourquoi nous avons construit notre propre panneau d’administration

Depuis quelque temps, LibreChat livre un panneau d’administration officiel. Ce panneau est
publié sous **AGPL-3.0**, donc sous une licence copyleft assortie d’une clause réseau. Qui
l’emploie et le modifie doit divulguer le code source, même lorsque le logiciel est uniquement
mis à disposition par le réseau et jamais distribué.

Pour un produit qui doit rester expressément permissif, c’est la mauvaise voie. Par conséquent :

- **Le panneau AGPL ne fait pas partie de la distribution.** C’était une solution transitoire
  pour des tests internes, avant que notre propre panneau ne soit terminé.
- **Notre panneau est une construction nouvelle et autonome** sous licence MIT. Il travaille
  contre la même interface d’administration de LibreChat, elle-même sous MIT.
- **Aucun code n’a été repris du panneau AGPL.** Le panneau a servi de modèle pour l’ergonomie,
  non de source. La même règle vaut pour les contributions extérieures.

Le résultat : vous pouvez héberger, modifier et redistribuer EU Cowork AI vous-même, sans
obligations de copyleft. C’est la véritable raison de ce surcroît de travail.

## Contribuer

Le code source se trouve dans le dépôt **`eu-cowork`** sur GitHub. L’adresse exacte figure
auprès de votre source d’approvisionnement ou vous est communiquée par votre fournisseur.

Les contributions se font sous forme de pull request contre `main`. Avant une première
contribution, un coup d’œil au fichier `CONTRIBUTING.md` du dépôt vaut la peine : il décrit le
déroulement. Les conventions contraignantes sur la structure, la construction, les contrôles, le
format des commits et le traitement des secrets figurent dans `AGENTS.md`.

Quelques points qui ont fait leurs preuves en pratique :

- **Où la modification a sa place.** Les sidecars, la distribution et la documentation vont dans
  ce dépôt. Les modifications de LibreChat lui-même vont dans le dépôt du fork.
- **Petite et limitée à un seul sujet.** Ne pas mélanger les reformatages et les modifications
  de fond.
- **Aucun secret dans le diff.** Les clés sont exclusivement référencées comme variables, et les
  nouvelles variables reçoivent un espace réservé dans le modèle de configuration.
- **Les contributions sont placées sous la licence MIT** de ce projet. Du code tiers ne peut
  être repris qu’avec une licence compatible et une mention d’origine. **Aucun code issu de
  sources AGPL**, en particulier pas du panneau d’administration AGPL de LibreChat.
