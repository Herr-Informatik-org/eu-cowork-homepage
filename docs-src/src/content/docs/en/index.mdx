## A note on the German labels

The administration and the chat interface currently ship in German only. Wherever this
documentation names a menu item, a tab, a field or a button, it therefore quotes the German
string you will actually see on screen and adds an English gloss, like this: open
**"Konfiguration"** (configuration). Nothing here describes an English interface that does not
exist.

## This documentation and LibreChat

EU Cowork AI builds on [LibreChat](https://www.librechat.ai), an open source chat
platform released under the MIT license. The chat interface, the agent system, file
handling and model connectivity come from there. We added everything a company needs
to run it under control: administration, permission management in front of the connectors,
a usage overview with budgets, and an installation package for your own server.

This documentation gives the overview and states where a building block comes from. Where the
LibreChat documentation goes deeper, we link to it rather than retelling it badly. The detailed
setup documents come with the delivery. Which building block comes from whom is set out under
[LibreChat and EU Cowork](/docs/en/referenz/librechat-und-eu-cowork).
