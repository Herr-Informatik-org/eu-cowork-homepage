## A note on the German labels

The admin panel and the chat interface currently ship in German only. Wherever this
documentation names a menu item, a tab, a field or a button, it therefore quotes the German
string you will actually see on screen and adds an English gloss, like this: open
**"MCP-Zugriff"** (MCP access) and set **"Server-Standard"** (server default) to denied.
Nothing here describes an English interface that does not exist.

## This documentation and LibreChat

EU Cowork AI builds on [LibreChat](https://www.librechat.ai), an open source chat
platform released under the MIT license. The chat interface, the agent system, file
handling and model connectivity come from there. We added everything a company needs
to run it under control: our own admin panel, a permission gateway in front of every
connector, usage metering with budgets, and an installation package for your own server.

This documentation describes the complete system and states at every point where a
building block comes from. Where the LibreChat documentation goes deeper, we link to it
rather than retelling it badly. Which building block comes from whom is set out in detail
under [LibreChat and EU Cowork](/docs/en/referenz/librechat-und-eu-cowork).
