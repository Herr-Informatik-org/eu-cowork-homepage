This page states in broad strokes what hardware a self hosted instance needs. It is written for
anyone who is ordering a VM or assessing an existing machine.

## Minimum and recommendation

| | Minimum | Recommended |
|---|---|---|
| CPU | 2 vCPU | 4 vCPU |
| Memory | 4 GB | 16 GB |
| Disk | 40 GB | 200 GB |
| Operating system | Ubuntu 22.04 LTS | Ubuntu 24.04 LTS |

For a single instance with few users, 80 GB is a comfortable figure. More pays off as soon as
many files are uploaded, because uploads drive the growth. Small instances are explicitly
allowed; the installation scripts warn on a thin machine but do not abort.

CPU load in normal operation is close to zero, because the computation happens at the inference
provider. Real peaks only occur when the search index is built, when the embeddings for file
search are computed and during code runs. What grows with the user count is above all the
memory of the application: up to around 15 people a small machine is enough, beyond that a
dedicated VM per instance pays off.

## Operating system and Docker

Tested are Ubuntu 22.04 and 24.04, recommended is 24.04 LTS. On other distributions the
installation keeps working, but behavior may differ.

Mandatory is **Docker Engine with Compose v2 as a plugin**. The Ubuntu package `docker.io` does
**not** include Compose v2; installing from the official Docker package source is the reliable
way.

## Disk

The Docker images occupy a few gigabytes once and are shared by all instances on the same
machine. After that, three things grow above all: the uploaded files, the database and the
container logs.

Disk is the first limit in operation, not memory. Set up an alert at 70 percent usage and clean
up unused images and the build cache regularly.
