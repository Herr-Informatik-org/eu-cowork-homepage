There are two ways to get your own instance. Either you use a hosted instance in Switzerland
and receive a ready made account, or you run the platform yourself on your own Linux server.
This page describes the second way in broad strokes.

<Steps>

1. **Provide a server**

   A Linux machine with a current container runtime. How large it should be is on the
   [system requirements](/docs/en/erste-schritte/systemanforderungen) page.

2. **Point the domain at it**

   The domain under which the instance should be reachable points to the server via DNS. The
   reverse proxy then obtains the certificate on its own, which requires the server to be
   reachable from the network.

3. **Install**

   The installation is guided and sets up the configuration and the services. Have the access
   to your inference provider at hand; out of the box that is [EuRouter](https://eurouter.ai),
   where processing takes place in the EU.

4. **Restrict access**

   Before the instance goes to the first people, define which email domains may register at
   all. That list is the decisive access protection, not the question of who knows the
   address.

5. **Create the first account**

   Setup creates the first administrator account, all further accounts are normal users.
   Afterwards create a second administrator account so that you do not lock yourself out.

6. **Set things up**

   In the administration you set up what applies day to day: create groups, release models per
   group, govern access to third party systems and invite your team members.

</Steps>

<Aside type="note" title="The step by step guide">
The complete installation guide comes with the delivery. It is part of the installation
package.
</Aside>
