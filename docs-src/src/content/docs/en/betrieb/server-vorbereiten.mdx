EU Cowork AI is self-hosted and runs as a Docker Compose application, the way LibreChat itself
provides for self-hosting. Before the application is installed, the machine has to be prepared
for it.

## What the server needs

- A current Linux distribution with long-term support.
- Docker with a current Compose plugin, the way LibreChat requires it for self-hosted
  operation.
- Enough memory, CPU and disk space for the planned number of users, see
  [System requirements](/docs/en/erste-schritte/systemanforderungen).
- A firewall that limits incoming connections to what is needed, plus time synchronisation and
  automatic security updates of the operating system.
- Log rotation for Docker, so that the container logs do not fill up the system disk over the
  course of weeks.

## Preparing the machine

These basics are set up before the application is added. The preparation concerns only the
operating system and the container environment; configuration and application follow in the next
step, see [Installation](/docs/en/betrieb/installation). The delivery package includes the
corresponding aids for this step.

<Aside type="note" title="Detailed instructions in the operations manual">
The exact sequence and the checklist after preparation are in the operations manual that
comes with the delivery package. Customers receive it together with their access.
</Aside>
