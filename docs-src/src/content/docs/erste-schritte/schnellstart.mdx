Es gibt zwei Wege zu einer eigenen Instanz. Entweder Sie nutzen eine gehostete Instanz in der
Schweiz und bekommen einen fertigen Zugang, oder Sie betreiben die Plattform selbst auf einem
eigenen Linux-Server. Diese Seite beschreibt den zweiten Weg in groben Zügen.

<Steps>

1. **Server bereitstellen**

   Eine Linux-Maschine mit aktuellem Docker und Compose v2. Wie gross sie sein sollte, steht
   unter [Systemanforderungen](/docs/erste-schritte/systemanforderungen).

2. **Domain eintragen**

   Die Domain, unter der die Instanz erreichbar sein soll, zeigt per DNS auf den Server. Das
   Zertifikat holt der Reverse-Proxy anschliessend selbständig, dafür muss der Server aus dem
   Netz erreichbar sein.

3. **Installieren**

   Die Installation läuft als Docker-Compose-Stack und wird von einem Skript geführt. Es legt
   die Konfiguration an, würfelt die Secrets aus und startet die Dienste. Bereitliegen sollte
   dabei der Zugang zu Ihrem Inferenz-Anbieter; im Auslieferungszustand ist das
   [EuRouter](https://eurouter.ai), wo in der EU verarbeitet wird.

4. **Zugang beschränken**

   Bevor die Instanz an die ersten Personen geht, gehört festgelegt, welche E-Mail-Domänen
   sich überhaupt registrieren dürfen. Diese Liste ist der massgebliche Zugangsschutz — nicht
   die Frage, wer die Adresse kennt.

5. **Erstes Konto anlegen**

   Das erste registrierte Konto wird automatisch Administrator, alle weiteren sind normale
   Benutzer. Legen Sie danach ein zweites Administratorkonto an, damit Sie sich nicht
   aussperren.

6. **Einrichten**

   In der Administration richten Sie ein, was im Alltag gilt: Gruppen anlegen, Modelle je
   Gruppe freigeben, Zugriffe auf Fremdsysteme regeln und Mitarbeitende einladen.

</Steps>

<Aside type="note" title="Die Anleitung im Einzelnen">
Die vollständige Installationsanleitung mit allen Befehlen, Konfigurationswerten und
Prüfschritten liegt der Auslieferung bei. Sie gehört zum Installationspaket und wird dort
gepflegt, wo auch die Skripte liegen.
</Aside>
